# אורן · סוויטת שיווק AI

ממשק All-in-One לשיווק ברשתות חברתיות לעסקים קטנים — עם הפרדה ברורה בין חשבונות עסקיים/יוצרים (פרסום אוטומטי) לחשבונות פרטיים (שיתוף מהיר בלחיצה).

## הרצה

```bash
npm install
npm run dev
```

פתחו [http://localhost:3000](http://localhost:3000).

## מה קיים כרגע

- פריסת 3 עמודות RTL (חשבונות | סוכן AI | תצוגה מקדימה)
- Design System נגיש: ניגודיות גבוהה, כפתורים 48px, פונט Heebo
- תגיות חשבון עסקי / פרטי
- מצבי הפצה: אוטומטי מלא / חצי-אוטומטי / ידני
- Mock data + TypeScript types ב־`src/types/social.ts`
